## 范围与方法

从上次最终门禁取历史性能回归、任一侧绝对重复性超限、CPU/request 超限的场景并集，共 140 个逻辑场景（原完整矩阵 180 个）。复用原实验冻结的 `1990c84` 基线和候选产物，逐场景 A/B/B/A，两侧各两轮；不重新构建、不启用插桩，保留正式样本数、10000 帧预热及原绑核。端点 CPU 0、2，Switch CPU 4、5，控制器 CPU 6–23。

两侧各完成 **280 条场景记录、110 次 ACK RTT**，功能失败 0；测量有效性、覆盖匹配、源码及产物指纹均通过。原失败实验完整保留。虽然通过 CLI 的 p99 manifest 入口调用，实际调用 `pair(..., diagnostic=False)`，成绩来自未插桩的冻结产物。
