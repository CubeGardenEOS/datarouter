# 100µs 与 PHP/Go 性能豁免重试（2026-09-12）

用户在上一轮失败后明确要求：“忽略PHP与Golang性能门限，采用更高自旋预算，重试。”本轮将 C 接收累计自旋上限从 50µs 提高到 **100µs**，保留固定预算、不随通知补充预算及休眠前释放引用；Switch 维护调度与 200µs 转发后自旋窗口保持上一轮实现。公共 ABI、共享内存布局和语言签名不变。

## 本轮门禁范围

- 任一端为 PHP 或 Go 的同语言/跨语言场景，仍采集全部原始性能数据、两轮重复性和 CPU/request，但不以这些性能门限拦截。
- 所有语言的功能正确性、测量有效性、样本/轮次完整性和指纹一致性仍是必要条件；候选全局空闲 CPU ≤一个核 1% 保留。
- 不涉及 PHP/Go 的场景继续承担性能退化 ≤5%、两侧绝对重复性 ±5% 及 CPU/request 增加 ≤5%。
- 豁免由实验清单 `excluded_performance_languages: ["go", "php"]` 显式传入。默认门禁没有豁免，不能通过源码全局关闭其他语言门限。结果保留原始 `regression` / `within_5_percent` / CPU `passed`，另用 `gate_applicable` 标明是否参与本次判定。

新增回归测试覆盖：任一端 PHP/Go 的豁免、保留原始失败数、其他语言仍被拦截、无效指标/缺失 CPU/缺轮/功能失败/空闲超限仍失败，以及非法豁免参数拒绝。23 项门禁和等待单元测试通过。

## 实验

独立结果目录：[high-spin-100-waive-go-php-52207ed0](../../datarouter-benchmark/results/high-spin-100-waive-go-php-52207ed0)。`authorization.json` 保存用户授权与预算口径，`candidate/datarouter` 是新冻结源码，`targeted.json` / `full.json` 保存两阶段清单。

历史源码固定为 `1990c84`，维持 WSL2、既定绑核、原样本数与 10000 帧预热。原 131 个失败场景加必要补充共 133 个，连同 PHP/Go 场景全部重测，不删除豁免场景的原始结果。两侧各 266 条记录，逐场景 A/B/B/A；所有构建先于计时，实验串行。只有定向门禁通过后才执行完整矩阵。

## 结果（2026-09-13 完成）

**本轮仍未达标。** 40 项安全检查、历史与候选 Go 各连续两轮功能测试及 23 项门禁/等待单元测试通过。定向测试两侧各完成 266 条记录、104 次 ACK RTT，功能失败为零，测量、覆盖及源码/产物/执行器指纹检查通过。

133 个逻辑场景中，67 个保留全部性能门禁，66 个涉及 PHP/Go 并应用授权豁免。未豁免指标仍有 22 项性能退化超限（17 个逻辑场景），以及历史 74 项、候选 57 项重复性超限；未豁免 CPU/request 全部通过。被豁免的原始失败仍保留：性能 19 项，历史/候选重复性分别 81/76 项。候选定向空闲 CPU 为单核的 0.23584%，通过 1% 上限。

通过 `cgeos-cli` 使用同一批未插桩产物串行补测 routed：8 条 A/B/B/A 记录测量有效、无功能失败，但 7 项比较和 2 项重复性检查失败。2ms 低频突发的候选 p99 为 102.629/98.748µs，历史为 34.919/42.360µs；10ms 空闲后首帧的候选 p99 为 153.698/185.847µs，历史为 178.808/172.187µs，第二轮退化约 7.93%。候选两组空闲 CPU 为 0.32959%/0.33012%，均通过；历史不承担候选绝对空闲预算。

定向门禁失败，因此未执行两侧各 360 条记录、110 次 ACK RTT 的完整矩阵，不能声称完整验收通过。新的未豁免失败并集为 60 个逻辑场景，原因与全部原始证据保存在 `retry-summary.json`、`targeted/` 和 `burst/`；现有证据不能把剩余超限唯一归因于自旋预算或外部调度。

测试运行器均已完成清理，最终进程与共享内存审计见实验目录的 `final-cleanup.json`。当前源码保留用户要求的 100µs 预算，尚未通过合入门禁；未提交、发布或更新装配指针。
